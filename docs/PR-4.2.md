# Product Lab 4.2: темы, Control Center и персональная аналитика

Платформа ранее имела одно оформление и подготовленную серверную аналитику, зависящую от хранилища. Теперь обучение, четыре темы, локальные правила доступа и персональная статистика работают без регистрации и БД. Изменение стоимости подсказки влияет на новые попытки; старые результаты сохраняют исторические правила.

## Изменения

- Light/Dark/Christmas/Finance, общие CSS-токены и тематические графики. Стикмены сохранены.
- `/settings-lab` с шестью разделами, четырьмя режимами доступа, порядком курсов, реальными ограничениями уроков/попыток, баллами, XP, наградами и конфигурацией навигации. Проверенный JSON импортируется локально или экспортируется для публикации через Git.
- `/my-analytics` с реальными добровольными локальными событиями, активным временем, графиками, тепловой картой и кликабельной воронкой. Сетевая отправка событий отключена; прежний адаптер сохранён отдельно.
- Совместимость локального прогресса, снимки правил, уникальные награды, исправление E/P-уроков и отдельного сброса. Серверная авторизация, API и SQL не менялись.

Локальный Control Center открыт намеренно и не даёт административных прав. Общая статистика всех посетителей не имитируется. Новые внешние сервисы и БД не подключаются.

## Проверка

Production build, 256 unit/integration-тестов, 1 тест bootstrap администратора, 45 Chromium e2e — прошли. Четыре темы проверены на 320/768/1440 px, контраст — на 16 образцах. Проверены защищённая админка, сохранение, реальные события, отсутствие сетевой доставки и повторного учёта времени. `npm audit`: 0 уязвимостей. Подробнее: [RELEASE-4.2.md](RELEASE-4.2.md).

Владелец прямо разрешил публикацию в main после проверок. Force push не требуется.
