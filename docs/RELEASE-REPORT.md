# Product Lab 2.0 — отчёт о реализации

## Результат

Работающая гостевая EdTech-платформа в отдельной ветке `feature/product-lab-2`. Основная production-ветка не изменялась. Существующие расчёты и исходные три кейса сохранены; старый прогресс мигрируется без удаления исходной записи.

## Созданные страницы

Лендинг, карта, каталог девяти миссий, последовательная миссия, библиотека 14 уроков, профиль навыков, рейтинг, сертификат, лаборатория, аккаунт, административная демонстрация/серверный допуск, методология, конфиденциальность и 404. Поддержаны старые hash-ссылки и прямое открытие новых путей.

## Реализовано

Светлый дизайн, локальная оптимизированная AI-иллюстрация с маркировкой, интерактивная демонстрация, сюжетные сообщения и последствия; девять математически согласованных кейсов и пять альтернативных наборов; 14 уроков и мини-задания; подсказки со штрафом; причины решения; сравнение попыток; навыки, XP и достижения; демо-рейтинг с согласием; игровой сертификат и настоящий PDF; демонстрационная оплата без реквизитов/списаний; кликабельные настраиваемые воронки с корректным порядком и окном событий, дедупликацией, фильтрами и CSV; лаборатория расчётов; добровольная локальная аналитика; синтетические административные отчёты; версиями управляемый редактор-песочница.

## Частично реализовано и требует внешней настройки

- Supabase Auth, профиль, импорт архива, серверные роли и административные адаптеры реализованы в коде, но настоящего подключения нет.
- SQL-схема, ограничения, RLS и RPC подготовлены; миграция не применялась к PostgreSQL.
- Для полного Connected Mode остаются опубликованные серверные варианты/рубрики, привязка миссий к RPC, серверный рейтинг и выдача сертификатов в пользовательском UI, проверка двух аккаунтов и офлайн-конфликтов.
- Демонстрационный редактор сохраняет локальные версии; его «публикация» намеренно не изменяет рабочий учебный каталог. Подключённая панель умеет сохранять серверные черновики, но промышленный процесс публикации контента ещё не реализован.
- Произвольного AI-преподавателя, реальной оплаты и официальных сертификатов нет.

Порядок подключения и безопасное назначение первого администратора — в `SUPABASE.md`. Клиент не может назначить себе роль; первый администратор назначается владельцем через доверенный SQL Editor по UUID зарегистрированного пользователя. Секретные service-role ключи в frontend не допускаются.

## Материалы

Предоставленный PDF Sommerville изучен; статистика ссылается отдельно на NIST/SciPy/statsmodels. `Product-Lab-dorabotki.docx` недоступен. Поэтому точное соответствие его текстам не заявляется: подсказки, причины, таблицы и альтернативные данные написаны по требованиям сообщения. Данные компаний, отзывы, рейтинг и админские демонстрации синтетические. Учебная эффективность пока не исследована.

## Выполненные проверки

- `npm run build`: TypeScript и Vite успешно.
- `npm test`: **137 тестов, 12 файлов — успешно**.
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`: **22 сценария — успешно**.
- Production smoke на `npm run preview`: **3 сценария — успешно** (маршруты, полная миссия MarketFlow, выдача и PDF).
- Браузерная проверка всех девяти миссий: 100/100, перезагрузка и переходы к теории без ошибок консоли.
- Проверены штраф 98/100, влияние причин на балл, повтор с другими данными, отсутствие накрутки XP, сохранение исходного v1.
- Проверены 320 px без горизонтального переполнения, все разделы лаборатории и админки на 390 px, версии редактора и отклонение неверных данных.
- Подстановка `role=admin`/`isAdmin=true` в localStorage не открыла серверную админку. Без Supabase вход/регистрация/восстановление честно недоступны.
- PDF проверен по сигнатуре `%PDF`. Сценарий оплаты не отправлял внешних запросов.
- `npm audit`: **0 известных уязвимостей** после обновления Vitest.
- Проверка исходников не обнаружила реальных секретов. Совпадение `sb_secret_*` есть только в отрицательном unit-тесте валидации конфигурации.
- SQL структурно проверен и разобран парсером; это **не выполнение миграции и не доказательство работы RLS на живом сервере**.

Предупреждение сборки о размере относится к PDF/fontkit (~1,16 МБ, ~512 КБ gzip), который загружается только при скачивании PDF. В начальную загрузку он не входит.
