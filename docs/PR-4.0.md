Product Lab 4.0 добавляет яркую иллюстрированную подачу и интерактивные модели в 39 уроках, сохраняя 5 курсов, 13 миссий, статистику, рубрику и локальный прогресс актуальной версии Claude (база main 8150904). Исправлены дубликат выбираемой метрики CloudNote, перенос ответа между уроками и мобильные переполнения.

Администратор входит через собственный Node API с scrypt, HttpOnly/Secure/SameSite cookie, отзывом сессии и распределённым ограничением попыток. Supabase отключён от runtime; добавлены PostgreSQL-адаптер, SQL-миграция, добровольные события и закрытый отчёт с drill-down воронками. Production-БД и секреты Vercel не подключены: без настройки вход закрыт, локальная демонстрация явно подписана. Инструкция: docs/ADMIN-4.0.md. Секретов в PR нет.

Проверено: production build, 219 unit/integration tests (включая PostgreSQL WASM), 1 тест первоначальной настройки, 36 Playwright-сценариев и целевые повторные проверки воронок, npm audit (0). Подробности и границы: docs/RELEASE-4.0.md.

Ветка предназначена для Preview и проверки владельцем. Автослияния и изменений production в этой задаче нет.
