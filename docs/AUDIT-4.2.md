## Найденные зависимости и дефекты

Серверная админка требует секреты и постоянное хранилище для production-сессий. PostgreSQL-адаптер и SQL существовали до 4.2; подключённой production-БД не обнаружено. Серверные файлы, API, миграции и авторизация оставлены без изменения. Новый локальный режим не использует их и не предоставляет прав.

Ранее интерфейс содержал жёсткие светлые цвета и разрозненные графические палитры. Они переведены на CSS-токены с сохранением исходной геометрии. Одна тёмная инверсия не применяется.

Парсер завершённых уроков принимал только префиксы A/B/C, хотя каталог содержит E/P: завершения этих курсов терялись после обновления. Теперь принимаются стабильные ID существующего каталога, добавлено покрытие сохранения. Явный сброс прогресса также исправлен: merge больше не восстанавливает данные, которые пользователь подтвердил удалить. Обычные обновления и сброс настроек прогресс не удаляют.

В исходном runtime была подготовлена same-origin отправка событий. Для требования «аналитика без сервера» она отключена: прежняя реализация и тесты сохранены в `serverTransport`, но приложение её не устанавливает. Локальная история и существующее согласие сохранены.

## Границы работы

Не создавались новые курсы ради номеров 2–9, внешние аккаунты, БД или платные подписки. Два курса по-прежнему пополняются; количество фактически доступных уроков обозначено в интерфейсе. Рейтинг остаётся демонстрационным, сертификат — локальным игровым. Новый Control Center открыт намеренно, содержит только публичные предпочтения и не является административным входом.
