# Product Lab 3.0 — аудит перед доработкой

Ветка: `feature/product-lab-3` (от `main` 8af00c4). Других изменений в удалённом репозитории на момент аудита нет (кроме старой `feature/product-lab-2`).

## Что есть фактически

| Область | Состояние |
|---|---|
| Фронтенд | React 18 + TypeScript + Vite, Tailwind 4, Recharts, Lucide. Маршрутизация по путям (`history.pushState`), fallback на `index.html` в `vercel.json`, поддержка старых `#hash`-ссылок. |
| Обучение | 9 миссий × 4 этапа, 14 уроков (A4/B5/C5), подсказки, причины решения, разбор, вторая попытка для 5 миссий. |
| Прогресс | localStorage v2 с миграцией v1, резервная копия файлом, слияние. |
| Лаборатория | 9 инструментов: глоссарий, формулы, A/B-калькулятор, дерево, воронка (кликабельная, детализация, CSV), удержание, юнит-экономика, литература, методология. |
| Сертификат | Условия выдачи, номер, псевдоним, PDF с кириллицей, печать, шуточное поздравление. |
| Supabase | Адаптер Auth REST, миграции (profiles, roles, courses, modules, lessons, cases, case_variants, attempts, answers, skill_scores, achievements, certificates, analytics_events, admin_audit_log, content_versions, guest_progress), RLS, RPC оценки/рейтинга/сертификатов/ролей. **Не подключено** — в production работает только гостевой режим. |
| Админка | Серверная проверка роли, честное состояние «не подключено». |
| Аналитика | События с согласием, локальное хранение, подготовленная доставка в Supabase. |

## Реестр проблем

### P0 — блокируют критерии приёмки
1. **Стиль похож на Claude:** кремовый/бежевый фон, терракотовые и коралловые акценты, звёздочки-«логотипы» (удалены в первом коммите ветки).
2. **Навигация:** нет понятной структуры «Курсы / Кейсы / Кабинет»; рейтинг убран из меню; кабинет разнесён по трём страницам (`/account`, `/skills`, `/certificate`).
3. **Объём обучения:** 14 коротких уроков в модальном окне — нет курсов, модулей, страницы урока, breadcrumbs, «Продолжить» и следующего шага.
4. **Ложная кликабельность:** карточки преимуществ со стрелкой ↗ без действия; карточки миссий поднимаются при наведении, но кликабельна только ссылка внизу; аватары «М А Ю» от удалённых демо-отзывов.
5. **Серверная рубрика рассинхронизирована** с клиентской (причины 0–5, три решения) — нужна миграция до подключения Supabase.

### P1 — важно
6. Нет кейсов по финтеху, мобильным приложениям, SaaS и e-commerce.
7. Рейтинг без данных: нужен явно помеченный демо-режим без Supabase, недельный/общий, топ-3, позиция пользователя, скрытие себя.
8. Нет поиска по курсам и урокам.
9. Цифры на главной («14 уроков», «9 миссий») захардкожены — расходятся с данными.
10. Графики используют жёстко заданные цвета вне дизайн-токенов.

### P2 — технический долг
11. Стили: `styles.css` (~80 КБ в 20 строк) с сотнями разрозненных оттенков; переопределения в `theme.css`.
12. Сценарии Playwright не запускались после последних изменений.
13. PDF-модуль ~1,1 МБ (загружается лениво).
14. Часть Connected Mode (серверные рейтинги/сертификаты в интерфейсе) требует проверки на реальном Supabase.

## План (по порядку документа)
Дизайн-система → навигация и интерактивность → курсы и уроки → кейсы → кабинет, рейтинг, сертификат → миграция рубрики → тесты на 320/375/768/1024/1440 → push ветки (Preview) → PR без автослияния.
