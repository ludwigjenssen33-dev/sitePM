# Product Lab 4.0

Интерактивная образовательная платформа: от проблемы в метриках до обоснованного продуктового решения. Для студентов, начинающих PM и аналитиков, которым мало знать формулы — нужна практика принятия решений.

Ценность MVP: увидеть бизнес-проблему, найти изменившуюся ветку метрик, сформулировать гипотезу, оценить эксперимент и объяснить управленческий выбор. Эффективность обучения ещё не подтверждена исследованием. Компании, показатели и сюжетные последствия вымышлены.

Версия 4.0 разработана в `feature/product-lab-4` от актуального GitHub `main` (`8150904`). Production не перезаписывается. [Аудит изменений 3.0](docs/AUDIT-4.0.md), [инфраструктура администратора](docs/ADMIN-4.0.md), [отчёт 4.0](docs/RELEASE-4.0.md).

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```bash
npm ci
npm run dev -- --port 5173
```

Открыть http://localhost:5173. Регистрация, ключи и внешние сервисы для обучения не нужны. Серверный API в локальном режиме подключён как Vite middleware. Для публичного предпросмотра frontend: `npm run build && npm run preview`; обычный Vite preview не исполняет серверные функции, для проверки входа используйте dev-сервер либо Vercel Preview.

```bash
npm run build
npm test
npm run test:admin
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Для других систем установите браузер: `npx playwright install chromium`, затем `npm run test:e2e` без CHROMIUM_PATH. E2E настоящего локального входа требует `npm run admin:setup`; при отсутствии приватного файла этот единственный сценарий будет явно пропущен. Остальные сценарии не используют реальные пользовательские данные.

Если среда не разрешает стандартный npm cache, используйте `npm ci --cache /tmp/productlab-npm-cache`.

## Что реализовано

- Пять курсов, 39 содержательных уроков; поиск, страницы программ, список модулей, «продолжить» и следующий урок. Тексты и стабильные ID версии Claude сохранены.
- Авторские векторные персонажи, новый светлый визуальный язык: электрический фиолетовый, лайм, коралловый, локальный Golos Text. Фотографии на страницах не используются.
- Визуальные модели перед объяснением: кликабельное дерево, воронка с деталями, удержание, распределение групп, интервал эффекта, влияние затрат и состава трафика. Сравнения гипотез, метрик тщеславия, discovery и roadmap. Внизу — полная теория, исходные числовые тренажёры, мини-задание и литература.
- 13 миссий × 4 этапа, математически согласованные деревья и расчётная статистика. Подсказки −2, решение с обоснованием, детерминированная оценка, немедленный разбор диагностики и частичный балл. Альтернативные данные там, где они уже подготовлены.
- Профиль навыков, история, XP без накрутки повторами, карта миссий, достижения и игровой сертификат с PDF/печатью. Результат можно передать ссылкой или PNG.
- Локальное сохранение, миграция v1 → v2 без удаления исходного ключа, приватные заметки, экспорт и объединение резервных копий. Версия релиза 4.0 не меняет схему прогресса.
- Лаборатория: глоссарий, формулы, A/B-калькулятор, размер выборки, деревья, интерактивная воронка, удержание, юнит-экономика, литература.
- Закрытые `/admin/login` и `/admin/dashboard`, Node API, scrypt, безопасные cookie, выход с отзывом сессии, серверная проверка каждого приватного запроса, ограничение попыток, защита POST по Origin.
- PostgreSQL-адаптер событий, повторяемая SQL-миграция, валидация схемы, дедупликация доставки, согласие. Панель с формулами метрик, динамикой, распределением баллов, сложностью заданий, популярностью курсов, CSV и drill-down воронок.
- Демо-оплата без карт и списаний, дружелюбная 404. Адаптивность, клавиатурный фокус, reduced motion, плавные переходы.

## Важно об административном входе и аналитике

**Действующая БД и серверные секреты Vercel не подключены этой работой.** Продакшен-вход до настройки закрыт, общая аналитика пользователей пока не собирается на сервере. Локальный прогресс одного браузера не выдаётся за статистику сайта. Supabase не используется в текущем runtime; исторические SQL и адаптер сохранены как наработки, а не как активная интеграция.

Для локальной первоначальной настройки:

```bash
npm run admin:setup
```

Логин и пароль будут записаны только в `.private/admin-credentials.json` (0600), серверу передаётся только хеш. Ничего секретного не выводится в консоль и не попадает в Git. Подробное подключение PostgreSQL, Vercel и безопасное обслуживание: [ADMIN-4.0.md](docs/ADMIN-4.0.md).

До подключения постоянного хранилища авторизованная локальная панель явно показывает синтетическую демонстрацию. При подключённой пустой БД показывает «Недостаточно данных», а не примерные числа. В production для входа требуются также постоянные сессии и распределённый лимит в БД.

## Архитектура

- `src/pages`, `src/components` — страницы и общие компоненты, тяжёлые разделы загружаются лениво.
- `src/features/learning` — полные/модальные уроки, визуальные сцены и тренажёры.
- `src/domain`, `src/lib` — прогресс, XP, достижения, сертификаты, математика, статистика и оценивание.
- `src/analytics` — ограниченная схема добровольных событий, same-origin доставка, воронки и расчёт отчётов.
- `src/auth/admin.ts`, `src/auth/useAuth.ts` — клиентская проверка серверной сессии; права в localStorage не хранятся.
- `server`, `api` — Node API, scrypt, сессии, PostgreSQL, лимиты, Vercel Function.
- `database/001_analytics.sql` — постоянное хранилище без публичного доступа.
- `src/theme.css` — общие токены; `src/design.css` — визуальный слой 4.0. Историческая геометрия сложных компонентов сохранена.
- `scripts/setup-admin.mjs` — приватная первоначальная настройка. Никаких серверных ключей в React.

Нормальный двусторонний z-тест долей с pooled SE под H₀; интервал эффекта с unpooled SE, интервалы отдельных долей Уилсона. Применимость нормального приближения проверяется; p-value не является вероятностью истинности гипотезы. Источник: `src/lib/statistics.ts`.

## Публикация на Vercel

Подготовить Preview из `feature/product-lab-4`: preset Vite, Node.js 22+, install `npm ci`, build `npm run build`, output `dist`. API живёт отдельно в `api/[...path].ts`; rewrite исключает `/api/`. Доступ к production остаётся через проверку и merge PR владельцем.

Для настоящего входа и общей аналитики нужны PostgreSQL, миграция и серверные env. Пошагово: [ADMIN-4.0.md](docs/ADMIN-4.0.md). Бесплатная доступная БД выбирается владельцем; платные подписки и внешние аккаунты автоматически не создаются. На Netlify статическое обучение работает, но серверная админка требует отдельного переноса API в Netlify Functions; текущая серверная конфигурация рассчитана на Vercel.

## Приватность и границы MVP

Обучение работает без аналитики. Только после согласия передаются анонимные ID, тип события, время, устройство, обобщённый канал, ID урока/миссии, этап, балл, подсказки и длительность. Нет email, произвольного текста, паролей или банковских данных. Не собираются нажатия клавиш. Удаление согласия останавливает передачу и очищает локальную очередь; уже отправленные события не удаляются автоматически. Raw-события хранятся до 90 дней при выполнении владельцем процедуры очистки.

Анонимные ID — браузеры, не подтверждённые люди. Баллы приходят от клиента и не являются серверной аттестацией. Рейтинг остаётся явно помеченной демонстрацией; сертификат игровой, локальный и не является документом об образовании. Два курса продолжают пополняться (6/9 и 5/10 уроков). В четырёх новых миссиях 3.0 нет альтернативных сценариев. PDF-чанк около 1,2 МБ загружается только при скачивании. Встроенный редактор контента и облачная синхронизация в 4.0 не подключены.

## Демонстрация за 3–5 минут

1. Главная: персонажи и ценность, найти конверсию в интерактивном примере.
2. Курсы → «Дерево метрик»: подвигать конверсию и увидеть выручку, прочитать объяснение, решить мини-задание и перейти к следующему уроку.
3. MarketFlow: выбрать конверсию → гипотезу и метрики → увидеть интервал и недобранную плановую выборку → продолжить по исходному плану и обосновать.
4. Разбор, навыки, достижения, поделиться результатом и образец сертификата.
5. Администратор: вход, статус источника, воронка → выбранный этап → события → CSV. До подключения БД подчеркнуть, что это демонстрация, а не реальная аудитория.
