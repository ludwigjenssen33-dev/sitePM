# Product Lab

**От проблемы в метриках до обоснованного продуктового решения.**

Работающий учебный MVP на русском языке. Пользователь выбирает кейс, локализует проблему в дереве метрик, формулирует гипотезу, выбирает метрики, интерпретирует A/B-тест и получает объяснимую оценку из 100 баллов.

## Продуктовая канва

- **Аудитория:** студенты 20–25 лет, начинающие PM, аналитики и кандидаты на стажировки.
- **Проблема команды (гипотеза):** знания о метриках и экспериментах трудно объединить в последовательное решение.
- **Ценность:** безопасная практика полного аналитического процесса с содержательной обратной связью.
- **MVP:** три независимых сценария, 19 слайдов, деревья, статистика, рубрика, рекомендации и локальный прогресс. Эффективность обучения пока не проверена пользовательским исследованием.

## Локальный запуск

Требуется Node.js 22+ и npm. Проверено на Node.js 24.19.0.

```bash
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (порт по умолчанию 5173). Сайт не требует backend, регистрации, ключей или платных API. В ограниченной облачной среде используйте `npm ci --cache /tmp/product-lab-npm-cache`.

```bash
npm run build   # TypeScript и производственная сборка в dist/
npm run preview # просмотр сборки
npm test        # Vitest
```

## Браузерные проверки

```bash
npx playwright install chromium
npm run test:e2e
```

Если Chromium уже установлен:

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Конфигурация автоматически запускает Vite или использует сервер на порту 5173. Проверяются верные и неверные ответы во всех кейсах, оценки 100/0, перезагрузка и сохранение, повторное прохождение, ссылки на теорию, сброс и отсутствие горизонтального переполнения на мобильном экране. Для кеша браузеров вне домашнего каталога можно задать `PLAYWRIGHT_BROWSERS_PATH=/tmp/product-lab-browsers` при установке и запуске.

## Возможности

- Главная, каталог, база знаний, личный прогресс, методология.
- MarketFlow: конверсия и недобор заранее запланированной выборки.
- StreamBox: удержание новых подписчиков через 30 дней.
- QuickFood: компромисс конверсии и маржинальной прибыли.
- Интерактивное дерево с деталями, изменениями и проверкой формул обоих периодов. На телефоне — вертикальное представление. Реализовано обычными React-компонентами без тяжёлой зависимости от React Flow.
- Четыре этапа; ответы фиксируются поэтапно. Эталоны доступны в итогах.
- Recharts: сравнение KPI, групп, интервал эффекта и оценка по пяти критериям. Используются только данные кейса, без вымышленных временных рядов.
- 19 адресуемых слайдов в трёх конспектах; переходы к конкретному слайду из разбора.
- localStorage: текущие ответы, этап, балл, лучший результат и дата. Повторная попытка сохраняет лучший балл. При недоступном хранилище показывается сообщение. Повреждённые записи не ломают приложение.
- Необязательное обоснование сохраняется, но не оценивается.
- Нет внешних шрифтов, аналитических трекеров или сетевых зависимостей основного сценария.

## Статистика и оценивание

`src/lib/statistics.ts` проверяет целочисленные размеры выборки и число успехов, вычисляет конверсии, абсолютный и относительный эффекты, двусторонний пуленный z-тест и приближённый 95%-й интервал с непуленной стандартной ошибкой. Если хотя бы в одной группе менее 10 успехов или неуспехов, p-value и интервал возвращаются как `null`: нормальное приближение не используется. При нулевой базе относительный эффект не определён.

Маркетплейс: p ≈ 0,1129, интервал включает ноль. Подписка: p < 0,0001, положительный интервал. Доставка: отрицательный значимый эффект конверсии; статистика денежного эффекта намеренно не рассчитывается без индивидуальных денежных наблюдений. Равные группы не считаются самостоятельным доказательством корректности рандомизации: это дополнительное условие сценария.

`src/lib/scoring.ts` — открытая детерминированная рубрика: 25 + 20 + 15 + 20 + 20. Выбор основной метрики даёт 10 баллов, контрольной — 5. В QuickFood диагноз «Маржа на заказ» даёт частичные 15/25, «Переменные затраты» — 25/25. Текст не оценивается.

## Структура

- `src/App.tsx` — страницы, навигация по hash, компоненты сценария и учебный диалог.
- `src/styles.css` — тёмная адаптивная тема, Tailwind CSS подключён через Vite.
- `src/data/cases.ts`, `lessons.ts` — сценарии и оригинальные учебные материалы.
- `src/lib/statistics.ts`, `metrics.ts`, `scoring.ts`, `storage.ts` — независимая предметная логика.
- `src/lib/feedback.ts` — интерфейс будущего провайдера комментариев и безопасный детерминированный fallback. AI не подключён. Серверный адаптер может получать только контекст разбора, не меняя эталон, статистику или баллы; API-ключ должен храниться только в серверной среде.
- `e2e/` — Playwright; `src/lib/*.test.ts` — Vitest.

## Ограничения

Нет AI, случайной генерации сценариев, серверной синхронизации и регистрации. Прогресс привязан к браузеру и может быть удалён при очистке его данных. Нет расчёта мощности: заданная плановая выборка — учебное условие. Нет индивидуальных наблюдений для анализа прибыли QuickFood. Эксперименты заданы заранее и не ветвятся после неверного выбора гипотезы; интерфейс явно это сообщает. Прототип не проводит реальные эксперименты и не подтверждает реальную бизнес-эффективность.

## Демонстрация на защите — 3–5 минут

1. **0:00–0:40.** Главная: аудитория, проблема и ценность. Покажите три кейса и объясните отличие последовательной задачи от теста.
2. **0:40–1:40.** MarketFlow: откройте A2, затем дерево. Выберите конверсию: 5% → 4,5%, −0,5 п.п. и −10% относительно. Подтвердите диагноз.
3. **1:40–2:30.** Выберите сокращение формы, конверсию и возвраты/ошибки оплаты. Подчеркните, что интерфейс — гипотеза, а не доказанная причина.
4. **2:30–3:20.** Сравните A/B: 5% и 5,5%, p ≈ 0,113, интервал включает ноль. Собрано 10 000 из 15 000. Выберите осторожную интерпретацию и продолжение по исходному плану.
5. **3:20–4:20.** Покажите оценку 100/100, критерии и ссылку C3. Обновите страницу: результат сохранился. Упомяните другой исход у StreamBox и неопределённость прибыли QuickFood.
6. **4:20–5:00.** Методология: источник Sommerville отдельно от статистики, вымышленные данные, ограничения и будущая проверка учебной эффективности.

## Фактические результаты проверки

В этой облачной среде выполнены `npm ci` по lockfile, производственная сборка TypeScript/Vite и 32 unit-теста — успешно. Пройдены 10 браузерных сценариев Playwright на системном Chromium: шесть прохождений с оценками 100/0, мобильная навигация и сброс, широкая главная, все 19 слайдов и полный путь трёх кейсов на экране 320 px. Во время шести основных прохождений ошибок в консоли не зарегистрировано. Дополнительно проверен полный путь MarketFlow в production-сборке с результатом 100/100 и без ошибок консоли. Проверки не заменяют исследование удобства с реальными студентами. Внешняя публикация не выполнялась.

Если вы выполняете `npm ci` при уже работающем Vite, перезапустите dev-сервер: переустановка удаляет его кеш оптимизированных зависимостей. При сообщении `Outdated Optimize Dep` используйте `npm run dev -- --force`. Это не требует изменения исходников или lockfile.
