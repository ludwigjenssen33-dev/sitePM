# Product Lab 4.2

Интерактивная образовательная платформа: от проблемы в метриках до обоснованного продуктового решения. Для студентов, начинающих PM и аналитиков, которым мало знать формулы — нужна практика принятия решений.

Ценность MVP: увидеть бизнес-проблему, найти изменившуюся ветку метрик, сформулировать гипотезу, оценить эксперимент и объяснить управленческий выбор. Эффективность обучения ещё не подтверждена исследованием. Компании, показатели и сюжетные последствия вымышлены.

Версия 4.2 развивает актуальный `main` (`e53b3dd`) в ветке `feature/product-lab-4-2`. Сохранены курсы Claude, визуальные уроки 4.0, монохромные стикмены и серверная админка. Публикация в main разрешена владельцем. [Аудит 4.2](docs/AUDIT-4.2.md), [Control Center и локальная аналитика](docs/CONTROL-CENTER-4.2.md), [проверки и ограничения релиза](docs/RELEASE-4.2.md), [инфраструктура администратора](docs/ADMIN-4.0.md).

## Локальный запуск

Нужны Node.js 22.12+ и npm.

```bash
npm ci
npm run dev -- --port 5173
```

Открыть http://localhost:5173. Регистрация, ключи и внешние сервисы для обучения не нужны. Серверный API в локальном режиме подключён как Vite middleware. Для публичного предпросмотра frontend: `npm run build && npm run preview`; обычный Vite preview не исполняет серверные функции, для проверки входа используйте dev-сервер либо Vercel Preview.

```bash
npm run build
npm test
npm run test:admin
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

Для других систем установите браузер: `npx playwright install chromium`, затем `npm run test:e2e` без CHROMIUM_PATH. E2E настоящего локального входа требует `npm run admin:setup`; при отсутствии приватного файла этот единственный сценарий будет явно пропущен. Остальные сценарии не используют реальные пользовательские данные.

Если среда не разрешает стандартный npm cache, используйте `npm ci --cache /tmp/productlab-npm-cache`.

## Что реализовано

- Четыре полноценные темы: Light, Dark, Christmas и Finance. Выбор в шапке, превью в настройках, сохранение после перезагрузки, тематические графики, плотность интерфейса, акценты, отключаемые анимации и декор. Стикмены сохранены; праздничные шапки появляются только в Christmas с включёнными украшениями.
- `/settings-lab` — открытый локальный Control Center с шестью вкладками. Свободный, последовательный, базовый и проходной режимы доступа; порядок курсов и исключения; правила уроков; стоимость/лимит подсказок; баллы и XP; достижения, сертификаты и навигация. Импорт/экспорт проверенного JSON, предпросмотр, сброс и публичная конфигурация для публикации через Git. Изменения действуют только в этом браузере и не дают прав администратора.
- `/my-analytics` — настоящая персональная статистика только этого браузера, по добровольному согласию. Сессии, активное время, уроки, кейсы, баллы, ошибки, подсказки, графики, интерактивная воронка, тепловая карта и детализация дней, фильтры, экспорт и отдельная очистка. События не отправляются на сервер.
- Пять курсов, 39 содержательных уроков; поиск, страницы программ, список модулей, «продолжить» и следующий урок. Тексты и стабильные ID версии Claude сохранены.
- Авторские векторные персонажи, новый светлый визуальный язык: электрический фиолетовый, лайм, коралловый, локальный Golos Text. Фотографии на страницах не используются.
- Визуальные модели перед объяснением: кликабельное дерево, воронка с деталями, удержание, распределение групп, интервал эффекта, влияние затрат и состава трафика. Сравнения гипотез, метрик тщеславия, discovery и roadmap. Внизу — полная теория, исходные числовые тренажёры, мини-задание и литература.
- 13 миссий × 4 этапа, математически согласованные деревья и расчётная статистика. Стоимость подсказки по умолчанию −2, настраивается для новых попыток; решение с обоснованием, детерминированная оценка, немедленный разбор диагностики и частичный балл. Альтернативные данные там, где они уже подготовлены.
- Профиль навыков, история, XP без накрутки повторами, карта миссий, достижения и игровой сертификат с PDF/печатью. Результат можно передать ссылкой или PNG.
- Локальное сохранение, миграция v1 → v2 без удаления исходного ключа, приватные заметки, экспорт и объединение резервных копий. Схема прогресса остаётся v2; добавлены необязательные ответы уроков, уникальные награды, дни обучения и снимки правил попыток. Исправлено сохранение завершённых уроков E/P.
- Лаборатория: глоссарий, формулы, A/B-калькулятор, размер выборки, деревья, интерактивная воронка, удержание, юнит-экономика, литература.
- Закрытые `/admin/login` и `/admin/dashboard`, Node API, scrypt, безопасные cookie, выход с отзывом сессии, серверная проверка каждого приватного запроса, ограничение попыток, защита POST по Origin.
- Сохранена подготовленная серверная инфраструктура 4.0: PostgreSQL-адаптер, миграции, валидация, дедупликация, панель и drill-down. В 4.2 доставка событий отключена, база данных не требуется и не подключалась.
- Демо-оплата без карт и списаний, дружелюбная 404. Адаптивность, клавиатурный фокус, reduced motion, плавные переходы.

## Важно об административном входе и аналитике

**Действующая БД и серверные секреты Vercel не подключены этой работой.** Продакшен-вход до настройки закрыт, общая аналитика пользователей пока не собирается на сервере. Локальный прогресс одного браузера не выдаётся за статистику сайта. Supabase не используется в текущем runtime; исторические SQL и адаптер сохранены как наработки, а не как активная интеграция.

Для тем, правил обучения и собственных показателей используйте `/settings-lab` и `/my-analytics`: им не нужны регистрация, административный пароль или база данных. **Настройка PostgreSQL из инструкции 4.0 не нужна для версии 4.2.** Серверная панель остаётся отдельной, безопасно закрытой инфраструктурой.

Для локальной первоначальной настройки:

```bash
npm run admin:setup
```

Логин и пароль будут записаны только в `.private/admin-credentials.json` (0600), серверу передаётся только хеш. Ничего секретного не выводится в консоль и не попадает в Git. Подробное подключение PostgreSQL, Vercel и безопасное обслуживание: [ADMIN-4.0.md](docs/ADMIN-4.0.md).

До подключения постоянного хранилища авторизованная локальная панель явно показывает синтетическую демонстрацию. При подключённой пустой БД показывает «Недостаточно данных», а не примерные числа. В production для входа требуются также постоянные сессии и распределённый лимит в БД.

## Архитектура

- `src/pages`, `src/components` — страницы и общие компоненты, тяжёлые разделы загружаются лениво.
- `src/features/learning` — полные/модальные уроки, визуальные сцены и тренажёры.
- `src/domain`, `src/lib` — прогресс, XP, достижения, сертификаты, математика, статистика и оценивание.
- `src/config/published.json` — публичные настройки по умолчанию; `schema.ts`, `store.ts`, `access.ts` — проверка, локальные переопределения, доступ; `theme.ts` — применение токенов.
- `src/analytics` — добровольные локальные события, сессии, активное время, воронки и персональные отчёты. `transport.ts` не отправляет данные; прежний `serverTransport.ts` сохранён отдельно и не подключён к приложению.
- `src/auth/admin.ts`, `src/auth/useAuth.ts` — клиентская проверка серверной сессии; права в localStorage не хранятся.
- `server`, `api` — Node API, scrypt, сессии, PostgreSQL, лимиты, Vercel Function.
- `database/001_analytics.sql` — постоянное хранилище без публичного доступа.
- `src/theme.css`, `src/design.css` — сохранённая геометрия 4.0; `src/palette.css`, `src/themes.css` — тематические токены; `src/control-center.css` — новые интерфейсы.
- `scripts/setup-admin.mjs` — приватная первоначальная настройка. Никаких серверных ключей в React.

Нормальный двусторонний z-тест долей с pooled SE под H₀; интервал эффекта с unpooled SE, интервалы отдельных долей Уилсона. Применимость нормального приближения проверяется; p-value не является вероятностью истинности гипотезы. Источник: `src/lib/statistics.ts`.

## Публикация на Vercel

Preset Vite, Node.js 22+, install `npm ci`, build `npm run build`, output `dist`. API живёт отдельно в `api/[...path].ts`; rewrite исключает `/api/`. Для Preview используйте рабочую ветку. Обновление production через main выполняется только с разрешения владельца; для этого релиза оно получено. Подключённая GitHub → Vercel интеграция запускает деплой после push; завершение нужно проверить в Vercel.

Новые темы, Control Center и персональная аналитика работают без серверных env. Публикация глобальных настроек: экспорт «Публичный конфиг для Git» → проверка и замена `src/config/published.json` → `npm run check:config`, тесты, сборка → коммит и деплой. Локальные настройки пользователей имеют приоритет. Подробно: [CONTROL-CENTER-4.2.md](docs/CONTROL-CENTER-4.2.md).

Историческая инструкция настоящего серверного входа: [ADMIN-4.0.md](docs/ADMIN-4.0.md). В рамках 4.2 новые БД, аккаунты и платные сервисы не создаются. На Netlify статическое обучение и локальные возможности работают; серверная админка требует переноса API в Netlify Functions.

## Приватность и границы MVP

Обучение работает без аналитики. После согласия **только в localStorage** записываются анонимные ID, тип события, время, устройство, обобщённый канал, ID урока/миссии, этап, балл, правильность, подсказки и длительность. Нет email, произвольного текста, паролей, банковских данных, содержимого клавиатурного ввода. Сеть для доставки событий не используется. Отключение записи удаляет локальные события; отдельный сброс аналитики сохраняет учебный прогресс и настройки. Исторические события этого браузера сохраняются при обновлении.

Сессия: 30 минут бездействия или максимум 8 часов. Время учитывается только в видимой активной вкладке обучения, короткими интервалами; общая отметка и Web Locks предотвращают повторный учёт. Последние секунды при аварийном закрытии могут не сохраниться. История ограничена 10 000 событиями, при нехватке места — 5 000; очистка данных браузера удалит локальную историю. Экспортируйте важные данные. Другие браузеры и устройства не синхронизируются. Удаление прошлых серверных данных, если они ранее собирались владельцем, не выполняется локальным сбросом.

Анонимные ID — браузеры, не подтверждённые люди. Баллы приходят от клиента и не являются серверной аттестацией. Рейтинг остаётся явно помеченной демонстрацией; сертификат игровой, локальный и не является документом об образовании. Два курса продолжают пополняться (6/9 и 5/10 уроков). В четырёх новых миссиях 3.0 нет альтернативных сценариев. PDF-чанк около 1,2 МБ загружается только при скачивании. Встроенный редактор контента и облачная синхронизация в 4.0 не подключены.

## Демонстрация за 3–5 минут

1. Главная: стикмены и ценность, переключить Light / Dark / Christmas / Finance.
2. `/settings-lab`: выбрать последовательный доступ, показать предпросмотр закрытого курса и цену подсказки. Изменения — только в этом браузере.
3. Курсы → «Дерево метрик»: подвигать конверсию и увидеть выручку, прочитать объяснение, решить мини-задание и перейти к следующему уроку.
4. MarketFlow: выбрать конверсию → гипотезу и метрики → увидеть интервал и недобранную плановую выборку → продолжить по исходному плану и обосновать. Разбор, навыки и поделиться результатом.
5. `/my-analytics`: включить локальную запись, пройти урок, открыть воронку и день на тепловой карте, экспортировать JSON. Показатели относятся только к этому браузеру.
