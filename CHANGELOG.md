## 1.4 — доработки к защите (текущая версия)

- Миссии снова открыты в любом порядке (ТЗ, п. 14); итоговая — после трёх завершённых. Последовательная дорожка 1.3 отменена.
- Диагностика: частичный балл за верную ветку на уровень выше и разбор сразу после подтверждения.
- Порядок вариантов ответа перемешивается; неверные варианты стали правдоподобными, к каждому есть пояснение «Почему не так».
- Причины решения — по документу доработок, верный набор вычисляется из статистики. Добавлено решение «Ограниченный пилот» (урок C5); для компромисса метрик в QuickFood оно верное.
- Таблица «Что можем утверждать» рассчитывается из данных каждого варианта.
- Подсказки свои для каждой миссии, со ссылкой на урок; в разборе отмечено, на каких этапах они брались.
- Теория перестроена по документу: 14 уроков (A4 «Метрики тщеславия», B2 «Сильный диагноз», C5 «Какое решение принять после теста»), у каждого урока своя схема.
- Дерево метрик показывает знаки операций и вложенные формулы; графики с ровными делениями, запятой и минусом.
- Новая палитра (насыщеннее и контрастнее), крупнее шрифты, мягкие анимации с учётом reduced motion.
- Без Supabase вместо нерабочей формы входа — гостевой профиль; рейтинг и админ-панель убраны из меню (адреса доступны владельцу напрямую).
- Демонстрационные отзывы заменены блоком «Три ловушки» со ссылками на миссии; подпись к ИИ-иллюстрации стала читаемой.
- Исправлено: попытка с причиной «денежный эффект не оценён» отбрасывалась при перезагрузке.

## 1.3

- Последовательная игровая дорожка с маркером пользователя, главами и финишем.
- Новая миссия открывается после предыдущей; прежние попытки сохраняют доступ. Подтверждённый сервером администратор видит все миссии сразу.
- Доступ к административным данным только после серверной проверки; демонстрационные метрики и вымышленные участники убраны из админки и рейтинга.
- Подготовлен добровольный сбор реальных событий гостей/аккаунтов в Supabase: дедупликация, ограниченные параметры, повторная доставка и сегменты. Без подключения метрики не выдумываются.
- Добавлена команда создания настоящего администратора со случайным паролем; сервисный ключ используется только доверенным оператором.
- Обмен результатом: ссылка, системное меню и PNG без имени, ответов и заметок.
- Возврат к незаконченной миссии, честная серия учебных дней без наказания за перерыв, следующий шаг после результата.
- Резервная копия прогресса, безопасное объединение импорта и локальный псевдоним.
- Плавные переходы с учётом reduced motion; убрано принудительное приветственное окно.
